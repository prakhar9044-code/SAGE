## ✨ Key Features

SAGE isn't just a study app; it's a complete, intelligent operating system for your education. 

### 🤖 1. AI-Powered Smart Video Hub
*   **Dynamic Search:** Type any subject, and SAGE fetches the best educational lectures directly via the YouTube Data API.
*   **Live Summarization:** Watch the video while SAGE's underlying **Groq LLM** generates instant, structured summaries and key takeaways in real-time.
*   **Save to Cloud:** Instantly save AI summaries to your Supabase-powered Notes database.

### 🧘‍♂️ 2. Zen Mode (Focus & Posture AI)
*   **Computer Vision:** Utilizes **TensorFlow.js** and **MediaPipe** directly in the browser to ensure absolute privacy.
*   **Posture Correction:** Maps your skeletal structure and calculates the ratio of your shoulders to your neck to warn you if you are slouching.
*   **Distraction Detection:** Employs `COCO-SSD` object detection to spot if you are holding a smartphone during a focused study session.

### 🎮 3. Gamification & Leaderboards
*   **Study Streaks:** Maintain your daily study streak, visualized beautifully on the dashboard.
*   **Achievements:** Unlock badges for consistency, high quiz scores, and late-night study sessions (Night Owl).
*   **Global Leaderboard:** Compete against other students. Climb the ranks by earning XP for completing tasks and acing quizzes.

### 🧠 4. Dynamic Web Quizzes & Flashcards
*   **Instant Quiz Generation:** Type any topic, and the AI will scrape the web to compile a 5-question multiple-choice test on the fly.
*   **3D Flashcards:** Interactive, flip-animated flashcards dynamically generated by the Groq AI for spaced repetition.

### 💻 5. Integrated CodeLab
*   **JavaScript Sandbox:** A built-in code editor for practicing algorithms without leaving your dashboard.
*   **Live Console:** Execute code safely and see real-time output right next to your study material.

## 🛠 Tech Stack

SAGE is built entirely with vanilla web technologies, supercharged by powerful cloud APIs and browser-based machine learning.

<details>
  <summary><b>Frontend Architecture</b></summary>
  <ul>
    <li><b>HTML5 / CSS3 / Vanilla JS:</b> Core structure and logic.</li>
    <li><b>CSS Variables & Glassmorphism:</b> Dynamic Light/Dark theming with premium frosted-glass UI elements.</li>
    <li><b>GSAP (GreenSock):</b> Buttery smooth entrance, stagger, and timeline animations.</li>
    <li><b>Lenis:</b> Seamless smooth-scrolling experience.</li>
    <li><b>Three.js:</b> 3D neural network background animations.</li>
    <li><b>Chart.js:</b> Interactive, animated progress and donut charts.</li>
    <li><b>Lucide Icons:</b> Clean, modern iconography.</li>
  </ul>
</details>

<details>
  <summary><b>Backend & Authentication</b></summary>
  <ul>
    <li><b>Supabase:</b> PostgreSQL database, user authentication (Email & OAuth), and real-time syncing.</li>
    <li><b>EmailJS:</b> Automated welcome emails upon user registration.</li>
  </ul>
</details>

<details>
  <summary><b>Artificial Intelligence</b></summary>
  <ul>
    <li><b>Groq API (Llama 3):</b> Ultra-fast LLM for the AI Tutor, Video Summarizer, and Quiz Generator.</li>
    <li><b>TensorFlow.js (COCO-SSD):</b> In-browser object detection for identifying smartphones.</li>
    <li><b>MediaPipe Pose:</b> In-browser skeletal tracking for posture monitoring.</li>
  </ul>
</details>

## 🚀 Quick Start / Installation

Because SAGE requires camera access for Zen Mode, it **must** be run on a local server. Opening the `index.html` file directly via the file system (`file:///`) will cause security blocks.

### Prerequisites
1. A code editor like [VS Code](https://code.visualstudio.com/).
2. The **Live Server** extension for VS Code.
